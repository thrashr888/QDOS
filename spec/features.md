Main Menu:
Directory, Tag, View, Copy, Move, Find, Rename, Space, Attribute, Print

Directory = Change current directory, make or remove directory, see directory tree
Tag = Tag groups of files, or clear all tags -- SPACE BAR tags highlighted file
View = View the contents of any file on the screen (in "ASCII" or "HEX")
Copy = Copy one or several files to another disk or directory
Move = Move one or several files from this directory to another directory
Erase = Erase one or several files from this directory
Find = Search all directories on the disk to find specified file(s)
Rename = Rename one or several files in this directory
Space = Show the total, used, and free space on any disk
Attribute = Change/change file attributes
Print = Print one or several files on the printer

Rename files: Highlighted, Tagged
Highlighted = Rename the highlighted file
Tagged = Rename all tagged files

Attribute files: Highlighted, Tagged, Display
Highlighted = Change attributes of highlighted file
Tagged = Change attributes of all tagged files
Display = Change display mode of highlighted file

F10 - Quit Q-DOS II
Press F10 again to quit, or RETURN for options
Press ESC to return to Q-DOS II
