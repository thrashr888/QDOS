SECTION 2: DOS COMMAND EXECUTION AND SHELL ACCESS
================================================================================

Purpose:   This command allows you to access the DOS prompt line
   so that you may enter any DOS command. This allows you
to execute any DOS command or application.

To use:    If you need to access the DOS command line, simply
    press the F6 function key. This will display a DOS
prompt in the place where Q-DOS II normally lists the path of the current directory.

Upon selecting the F6 command, the command line appears near the top
of the screen and a cursor is displayed allowing you to enter the
desired commands.

You may enter any command you wish (i.e.  execute a program,
perform a CHKSK or DIR on a disk...etc.).

Pressing F8 will immediately put you into DOS; if you use this
function key, you must type "EXIT" to return to Q-DOS II.

The command actually runs another copy of COMMAND.COM on top of Q-DOS II.

SECTION 4: FUNCTION KEY SHORTCUTS FOR DOS COMMAND LINE
================================================================================

F2 will type the highlighted file name (not including the extension).
F4 will type only the extension of the highlighted filename.
F6 will type the filename complete with its extension.

The F3 key (and ctrl-R) will redisplay the last-used command.

The editing keys (INS, HOME, END, and the arrow keys) are available.

The INS key toggles between overwrite mode (small underline cursor)
and insert mode (larger block cursor).

SECTION 13: COMMAND LINE USAGE CONTEXT
================================================================================

The lower left-hand side of the screen displays
the special function keys that work with this command.

At this point, you may enter any command you wish.

This allows you to run programs files and combine them with selected data files.

For example, suppose you wanted to find a word processing document
and use the word processor to edit it. You could use Q-DOS II to
quickly find the document.

Another example would be to have Q-DOS II find the FORMAT command.
After highlighting it, pressing F6 would bring up the DOS prompt,
pressing F2 will display the first part of the filename.

================================================================================
SECTION 14: SHELL AND COMMAND INVOCATION DETAILS
================================================================================

Q-DOS II is still in memory, taking up part of RAM. If you need all
or part of this RAM, you should quit Q-DOS II and then run your other
programs.

The command actually runs another copy of COMMAND.COM on top of Q-DOS II.

If your computer has more than 640K of RAM, you might execute from within Q-DOS II.
