DOCUMENTATION REFERENCES
================================================================================
Purpose:   The PRINT function allows you to print the Directory
To use:    Upon selecting the PRINT command, you are given 4 options.
           Selecting HIGHLIGHTED or TAGGED will print the files.
           LISTING will direct Q-DOS II to print the sorted directory listing screen as displayed.
           DIR MAP will produce a printed hard copy of the Q-DOS directory map.
