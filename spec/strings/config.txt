QDCOLOR COLOR THEME CHANGER
================================================================================

COLOR CONFIGURATION OPTIONS:

Color Settings Menu:
 M - Standard monochrome
 C - Standard color
 1 - Adjust cursor bar color
 2 - Adjust line color
 3 - Adjust command description color
 4 - Adjust heading color
 5 - Adjust commands/data color
 6 - Adjust background color

COLOR SELECTION INSTRUCTIONS:
Q-DOS II may be set up to run in either black and white or color,
the default color configuration being black and white.
Would you like Q-DOS II to run in color? (Y/N)

When you press a key, a screen will be displayed which is almost
identical to the main screen of Q-DOS II.  In the lower right
corner of the screen you will see a color selection box, and the
color selection keys will be flashing.  Pressing any one of the
color selection keys will change the color of some part of the
main screen such as the cursor bar color, background color, etc.
After you have adjusted all of the colors to your taste, press
the ENTER key to save your selections.

QDCOLOR PROGRAM FLOW:
The program QDCOLOR.COM will automatically be executed next, and
it will allow you to select the colors that Q-DOS II will use for
its display screens.  Should you later decide that you would like
to change the colors, you may do so at any time by simply running
the QDCOLOR program.

QDCOLOR COLOR ADJUSTMENT KEYS:
Press letter key to adjust.
Press F1 to read & display current colors.
Press ENTER to save colors or ESC to quit.

SAVE/CANCEL OPTIONS:
To save the current configuration and exit, press the ENTER key.
To exit without saving the current configuration, press the ESC key.

EDITOR CONFIGURATION:
Q-DOS II can now edit any file under 61,440 bytes (60k) in length by
simply pressing the F9 key
Q-DOS II comes with the F9 key pre-configured to run the editor,
located in the C:\QDOS directory.  If you do not want to use this
editor, or you wish to place it onto another drive or into another
directory, you MUST use the QDSTART program to modify QD2.EXE before
you use it.

DEFAULT EDITOR PATH:
CC:\QDOS\QED.EXE

DEFAULT HELP FILE PATH:
C:\QDOS\QD2.HLP

DISK LOGGING CONFIGURATION:
Automatic disk-logging on or off
Do disk logging on all drives, or only on hard disks
Log file location: root directory of each disk
Log file is created automatically if not found
Log file is updated when directories are made/removed
Can force rescan with SCAN command

LOGGING FEATURES:
Q-DOS II will now automatically maintain a directory-log file
This file is kept in the root directory of each disk
Q-DOS II can now display the directory structure of any disk in about 1/2 second
The logging feature can be turned on or off

FILE COMPATIBILITY NOTES
================================================================================

RUN FROM APPROPRIATE DIRECTORY:
Change to the directory containing the QD2.EXE program

FILE STATE REQUIREMENTS:
The QD2.EXE file should not be marked as read-only
Turn-off the read-only attribute before running QDCOLOR or QDSTART

AUTOMATIC EXECUTION:
The program QDCOLOR.COM will automatically be executed next

WILDCARD PATTERN EXAMPLES:
QD*.* would match both "QD.EXE" and "QDCOLOR.COM"
In the case of "QDCOLOR.COM", there are none between the "D" and the "."
