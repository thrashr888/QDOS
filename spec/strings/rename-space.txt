RENAME COMMAND STRINGS
======================

Command Description:
- RENAME command lets you assign new names to files
- Q-DOS II lets you mark files and move, copy, rename, print, or erase
- Six Q-DOS II commands -- COPY, ERASE, RENAME, PRINT, ATTRIBUTE, and

User Interface:
- Purpose: The RENAME command lets you assign new names to files
- First, select the files you wish to RENAME. Then select the RENAME command.
- If you select multiple files, the RENAME command will open a dialog box with:
  (1) a display of the file to be renamed, and (2) an input box for the new name.
- Type the new name and press ENTER. Q-DOS II lists them all and allows you to rename them one at a time.
- You may exit the RENAME command at any time by pressing ESC.

File Behavior:
- When you rename files, Q-DOS II will not re-sort the files unless you RESCAN the disk.
- Files that were tagged before you renamed them will no longer be tagged.

Tagged Files:
- ATTRIBUTE, PRINT, or RENAME commands to all the tagged files at once.
- RENAME the TAGGED files when no files are tagged.

Error Messages:
- Can't rename the file --
- CAN'T RENAME THE FILE

Error Details:
- There are three reasons why DOS cannot rename a file:
  1. The file has the READ-ONLY attribute. To rename it, select the ATTRIBUTE command, and change its attribute. Only files that can be renamed (or erased) can be renamed once the READ-ONLY attribute is reset.
  2. You must use DOS 3.0 or higher to rename directories. If you rename a directory, you must then re-SCAN the disk to verify the rename.
  3. The file or directory does not exist. Make sure the path you specify is correct and you wish to rename it.
- rename either the file in the source directory, or the one in the target directory.
