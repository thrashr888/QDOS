SPECIFIC COMMAND DESCRIPTIONS
==============================
F1 - Help: Press the F1 key. Q-DOS II will then display help
F2 - Status Screen: Shows search specifications and sort information
F3 - Change Drive: Change to a different disk drive
F4 - Previous Directory: Switch to previously viewed directory
F5 - Change Directory: Highlight the directory entry and press F5
F6 - DOS Command: Display a DOS command line interface
F7 - Set Search Specification: Configure file search attributes and specifications
F8 - Sort Files: Select sort method and direction
F9 - Edit: Start your configured editor to edit the highlighted file
F10 - Quit: Press F10 to quit Q-DOS II (press again to confirm exit)


DIALOG/CONFIRMATION MESSAGES
=============================
To make your selection, press the up and down arrow keys to highlight the appropriate option, and then press the ENTER key.
To exit to DOS, select the exit option, or press the ESC key.
To save the current configuration and exit, press the ENTER key.
To exit without saving the current configuration, press the ESC key.
Disk has been changed -- press any key to go to main menu
Press F10 again to quit, or RETURN for options
