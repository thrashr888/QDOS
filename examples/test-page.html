Welcome to Q-WEB

This is a test page for the Q-WEB text-based browser.

Features

  • HTML to text conversion
  • Link extraction and navigation
  • Keyboard-driven interface
  • History support

Navigation

Use these keys to navigate:

  • Tab - Next link
  • Shift+Tab - Previous link
  • Enter - Follow link
  • Backspace - Go back
  • g - Go to URL
